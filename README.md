# Word Duel — Multiplayer Word Game

A browser-based multiplayer word game where friends, family, and classmates compete to create words from shared letter tiles.

**Status:** Deployed  
**Development:** AI-assisted web application

## Play Word Duel

**[Play the live game](https://word-duel-sarah-cole.hillychant.chatgpt.site/)**

No ChatGPT account required.

## Game Features

- Supports 2–4 players per game room
- Six-character room codes for joining games
- Five rounds of word challenges
- 60-second timer per round
- Word validation and point-based scoring
- Shared scoreboard and final winner announcement
- Browser-based gameplay across devices

## How to Play

1. Open the game and create a room.
2. Share the room code with another player.
3. Other players join using the code.
4. Start the game and create words of three or more letters from the available tiles.
5. Earn points and compete across five rounds.
6. The player with the highest total score wins.
